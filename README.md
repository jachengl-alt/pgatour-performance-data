# PGA Tour Performance Data
1. pga_raw_combined_master.csv: This is the primary raw dataset. It contains a comprehensive collection of professional golf statistics, including "Strokes Gained" metrics, putting averages, and around-the-green performance. The file features complex, multi-level headers and raw string data that require significant cleaning.
2. PGA_Data_Master_Cleaned.csv: The output of the data cleaning process. This standardized, analysis-ready dataset contains key performance metrics such as Avg_Drive_Distance, GIR_Percentage, Scoring_Avg, and financial outcomes like Money and Wins for players across multiple seasons.
3. PGA Tour Scraped Code.ipynb: This notebook contains the initial data acquisition logic. It utilizes web scraping to gather season-by-season schedule and winner information from Wikipedia, employing ethical scraping practices like User-Agent masking and timed delays. Along with CSV historical files found on GitHub.
4. pga clean data coding.ipynb: This script focuses on the "Tidy Data" framework. It automates the cleaning of raw CSVs by standardizing player names, extracting numeric values from strings (removing $ and % symbols), and coalescing inconsistent column headers into a single master schema.
5. Machine Learning Lineaer Regression.ipynb: This notebook performs the core statistical analysis. It uses Lasso Regression to rank the most important predictors of success and K-Means Clustering to identify distinct player archetypes, such as "Bombers" versus "Tacticians". It also includes an ROI analysis to determine which playstyle is most financially lucrative.
6. Master step by step file.ipynb: A comprehensive, end-to-end master script. It consolidates the entire project workflow—from data acquisition and cleaning to machine learning and final visualization—investigating which technical disciplines are the strongest predictors of elite scoring and earnings.
